TYPE IN PRIVATE.
SEND ONLY COVER TEXT.

Refract keeps your real message inside the keyboard, encrypts it, and uses an on-device model to encode it into ordinary-looking text. The app beneath the keyboard receives the carrier—not your private draft.

PRIVATE SPEECH SHOULD NOT DEPEND ON INSTITUTIONAL RESTRAINT.

A platform that receives plaintext can inspect it, retain it, or be compelled to reveal it.

Whether the threat is routine platform surveillance, government overreach inside the EU, or Putin’s security state, the safe assumption is the same: do not hand the intermediary the private message.

Refract changes that boundary. Your messaging app gets the cover. The private writing stays with the keyboard.

THE MESSAGE TAKES A DIFFERENT PATH.

Refract adds one narrow private layer to AOSP LatinIME. Normal typing remains a normal Android keyboard; Private mode reroutes text before it reaches the host editor.

  1. 01

    Compose inside the keyboard

    Keystrokes enter Refract’s private draft buffer. The host InputConnection receives nothing while you write.

  2. 02

    Authenticate the payload

    Paired conversation state encrypts, authenticates, and orders the message. State advances only after carrier insertion succeeds.

  3. 03

    Generate locally

    Gemma runs through LiteRT-LM on the phone’s CPU or GPU. The ciphertext is encoded through the model’s token choices—no network request is needed.

  4. 04

    Insert only the carrier

    Refract commits the completed carrier to the active message field. You review it, then send it with the app you already use.

NO SECRET TOKEN CROSSES THE CHAT.

Pairing is a two-QR X25519 exchange. Each code contains a temporary public key—not the conversation key. Both phones derive the same secret independently, then show five safety words for comparison.

Use a different channel. Send the QR outside the chat you are protecting. Email is a pragmatic option; delete it after pairing.

KNOW THE BOUNDARY BEFORE YOU TRUST IT.

What Refract changes

  • The host app does not receive the private draft.
  • The manifest requests no internet or network-state permission.
  • Pairing exchanges public keys and verifies the transcript.
  • Confirmed conversation keys are wrapped by Android Keystore.
  • The private composer blocks screenshots while visible.

What Refract does not claim

  • It does not hide traffic metadata or provide anonymity.
  • It cannot secure a compromised operating system or unlocked device.
  • Its carriers have not had an independent steganalysis audit.
  • Receiving, decoding, and missed-message recovery are not implemented yet.
  • It is an active prototype, not a promise of perfect secrecy.

EARLY USERS SHOULD BE SCEPTICAL.

The current build proves the private composer, offline pairing, sender chain, local model loading, and carrier insertion path. Read the code. Exercise the cancellation paths. Check what reaches the host editor. Report the assumption that fails.
